# Декларативные типы для API Базис V20

В файле `bazis-api.d.ts` описаны классы, свойства и методы API V20 скриптов Базис для сторонних редакторов кода, которые поддерживают LSP (Language Server Protocol) и typescript-language-server.

В файле `jsconfig.json` описаны правила для typescript-language-server, которые предотвращают отображение большого количества ошибок в активном буфере.

Если вам критичны базовые ошибки синтаксиса, рекоменду поставить `ESLint`.
